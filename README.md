# 叙镜 · NarraLens

> 让文案成为视频。

**文案驱动的视频制作工作台 · v2.5.0**

[English](README-en.md) · [MIT许可证](LICENSE)

## 项目简介

叙镜（NarraLens）是一款以完整文案为核心的视频制作工作台。用户提供文案和本地视频素材，软件利用素材库分析与检索结果，为文案组织镜头，生成连续配音、字幕和成片；按需要加入背景音乐和解释动画。

适合影视深度解析、长篇解说和围绕已有文案组织画面的制作流程。文案可以与单集剧情保持较弱对应关系，多个素材库可以联合检索。最终画面与原素材、分析质量和配置的模型能力有关，生成后可查看匹配详情。

## 主要功能

- **素材分析与复用**：视频素材和音频素材独立登记，保存分析结果，后续项目继续使用已有结果。
- **完整文案输入**：支持粘贴正文及TXT／Markdown，原稿和项目输入副本可追溯。
- **文案驱动画面组织**：从一个或多个视频素材库检索、确认画面，连续配音下可安排多个镜头。
- **长段配音**：按原文段落建立配音块，支持手动合并／拆分；当前默认块间停顿3秒。
- **本地字幕对齐**：使用独立Qwen3 ForcedAligner环境生成字词时间；关闭时保留字幕并按文字估算时间。
- **单行字幕排版**：字号可自定义，按文字实际宽度和可用时间调整字幕切换。
- **自动BGM**：分析音频库中的整首音乐，再按文案主题和情绪选曲，支持整篇单曲与分段配乐。
- **解释动画**：支持自动、手动及混合插入，原文范围确定时机，可预览对应配音时间。
- **项目管理**：新建、查看、复用、删除，与制作设置和推进分开。
- **分阶段继续**：保留通用继续与1–5阶段入口，使用已有配音和有效结果恢复制作。
- **模型集中配置**：按用途选择接口、实际模型和参数，文案及视觉各有后备配置。

## 运行与模型准备

### 从源码运行

需要Python 3.12、FFmpeg及本项目的Python依赖。在准备好的环境中，从源码目录运行：

```powershell
python -m pip install -r requirements.txt
python -m streamlit run webui.py --server.address=127.0.0.1 --server.port=8501
```

浏览器打开 `http://127.0.0.1:8501`。源码不包含本机Conda环境、模型权重、原素材或生成结果。本地字幕对齐和解释动画需要另行准备对应环境、模型及Node／Remotion依赖。

本仓库从NarraLens v2.5.0开始记录独立提交历史，原项目来源和许可证保留。施工文档仅在维护者本地保存。

### 模型使用

应用在本地管理素材、项目与生成结果。文本／视觉／音频分析、配音是否访问外部服务，由当前选择的模型接口决定；在素材分析时，所选服务会接收对应文案、字幕、图片或整首音频。

进入“模型配置”查看配置名称、实际模型、用途、字段状态和参数。接口字段已填写只说明配置完整性，真实能力与连接需通过显式检查或对应流程确认。

文案项目的TTS沿用MiMo／Edge支持范围，原视频制作保留其既有配音服务。文本和视觉后备可配置独立接口及凭据，按现有重试／后备规则执行。

本地字幕对齐使用独立模型环境。当前部署是AMD ROCm环境，框架以cuda设备接口访问GPU；运行首页或主应用页面不会直接加载该对齐模型。关闭本地对齐可使用文字估时，需接受字幕时间误差。

解释动画使用单独准备的Node、Remotion依赖和浏览器渲染环境。

## 完整文案制作流程

### 1. 配置模型

在“模型配置”维护所需接口、凭据和参数；各工作区选择对应用途的配置。已导入定义可直接编辑，无需每次重新导入。

### 2. 建立视频素材库

选择视频和字幕目录，扫描并检查匹配关系，再登记、分析素材。支持ASS／SSA及SRT；多个字幕候选需选择目标字幕，ASS可选择中文样式或所在行并检查预览。

视频素材通常保留原路径引用，库内保存字幕副本、抽帧和分析结果。成功分析可复用，停止后可以继续。

### 3. 按需要建立音频素材库

登记本地音乐，通过支持音频输入的配置分析整首音频。建立好的情绪、风格、节奏和用途资料供自动BGM选择，也可手动选曲。

### 4. 登记文案项目

进入“项目管理”，粘贴完整文案或上传TXT／Markdown，选择一个或多个视频素材库并创建项目。

### 5. 在制作工作台推进

选择项目后设置：

- TTS服务、音色、参考音频、配音块和衔接停顿。
- 文案／字幕／视觉模型及后备。
- 字幕字号、画幅及输出选项。
- BGM来源、配乐方式和音乐音量。
- 解释动画模式、手动节点和内容。

保存设置并开始制作。文案与素材分析、配音、字幕对齐、画面检索及动画、配乐、视频合成按流程执行。

### 6. 查看与调整

查看成片、匹配详情、字幕／动画方案及项目内诊断记录。已经开始的项目可通过复用副本应用需要重做的设置；来源项目与已有产物保留。


## 数据保存位置

以下均相对于当前代码目录：

| 位置 | 内容 |
|---|---|
| config.toml | 应用及中央模型配置，包括服务凭据 |
| storage/libraries/ | 视频素材库登记、字幕副本、抽帧及分析 |
| storage/audio_libraries/ | 音频库登记、分析与相关派生资料 |
| storage/narration_tasks/项目ID/ | 文案项目的输入副本、设置、配音、字幕、计划、缓存与日志 |
| storage/narration_tasks/项目ID/final.mp4 | 文案项目成片 |
| storage/narration_tasks/项目ID/motion/ | 解释动画计划、资产及执行记录 |
| storage/tasks/ | 原视频制作流程的任务产物 |

视频与音频原文件通常保留在登记时的原位置。移动或删除原素材会影响后续读取；按现有库管理入口更新登记或重绑定。

## 继续、复用与删除

项目可使用通用继续或编号1–5的阶段入口，从指定阶段推进。匹配的已有成果可复用，具体前置条件由各阶段验证。

改变已经生成的配音／字幕／动画或配乐时，按制作工作台提供的副本入口操作。

删除项目的位置：**项目管理 → 选择项目 → 管理项目 → 检查文件与删除范围 → 确认 → 永久删除当前项目**。删除清理当前项目及其产物，原素材与外部文案文件保留；运行中的关联资源需要先停止。

代码ZIP与项目数据承担不同恢复用途：代码备份通常排除storage、媒体、环境和权重；需要保存成片和项目成果时另外备份对应数据。
